# Think Board App

## Project Overview

**Think Board** is a full-stack web application built with **React** for the frontend and **Node.js** with **Express.js** for the backend.ThinkBoard enables users to add, edit, delete, and categorize notes while maintaining an intuitive, user-friendly interface.

## Project Structure

### Backend (Node.js)
   - Use **Express.js** to build the API.
   - Set up a **MongoDB** database (or an alternative if preferred).
   - Includes setting up the server, connecting the database, writing API routes, and handling requests (GET, POST, PUT, DELETE).

### Frontend (React)
   - Learn and implement **React basics** like components, state, props, and hooks (`useState`, `useEffect`).
   - Build the user interface with forms for submitting complaints.
   - Use **Axios** or **Fetch** for interacting with the backend API.
   - Implement **React Router** for navigation.

## Technologies Used
- **Frontend**: React, React Router, Axios (or Fetch)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (with Mongoose)
